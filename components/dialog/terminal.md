# terminal (a subprocess in a frame)

**Language**: English · [繁體中文](terminal-zh_TW.md)

## Purpose

A subprocess running in a frame (a shell, an editor, a remote session): every key goes to it, only the exit key belongs to the app (F1, K10, `Alt-Esc` confirming first); it takes all the room there is (F7's terminal exception).
