# number（數字）

**Language**: [English](number.md) · 繁體中文

## 用途

輸入一個數字：port、秒數、次數、欄數。

## 長相

- 骨架照 [`text`](text-zh_TW.md) 的「長相」（單行 input popup）。

## 按鍵

- 編輯鍵與貼上照 [`text`](text-zh_TW.md) 的「按鍵」「貼上的換行與 Tab」。

## 值

user 2026-10-07 定。

- **打字當下只收這個欄位可能用到的字**：數字；欄位允許負數才收 `-`，允許小數才收 `.`。其他鍵按了沒反應（sshu 的 Port
  就是這樣）—— 不可能對的字沒必要讓它進來再擋。貼上照 text 的規則：只留下會收的字。
- **範圍在 `Enter` 時檢查**，錯了寫錯誤列（`Port must be 1-65535`）：範圍要等整個數打完才知道，打到一半不能擋（要打 `22`，
  打第一個 `2` 時還不到最小值）。
- **說明列寫出範圍**（`Port, 1-65535`），不要等打錯才知道。
- 現況：locku 的數字設定什麼字都收、`Enter` 才驗，要改成打字當下過濾。
- 不做 `↑`/`↓` 加減：家族現在沒有，範圍小、要點選的值用 slider 或清單。
