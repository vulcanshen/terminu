# textarea（多行文字）

**Language**: [English](textarea.md) · 繁體中文

## 用途

輸入多行文字：網頁表單的留言、說明。程式碼、設定檔這種「一行就是一行」的內容，交給使用者的 `$EDITOR`（例：sshu 的 File transfer），
不用 textarea。

## 長相

**一行太長時自動折行，左邊有行號**：

```
┃  1 Thanks for the quick reply. The new   ┃
┃    build fixes the crash on start.       ┃   ← 同一行折下來：行號欄空白
┃  2                                       ┃
┃  3 One more thing: the export button█    ┃   ← 游標所在的行
```

- 超過框寬就接到下一列畫，不左右捲。折行只在畫面上，值裡不多出換行。寬度照顯示寬度算，一個字不折成兩半。
- **行號**：每一行的第一列畫行號，靠右對齊、後面空一格；折下來的列行號欄空白 —— 看得出哪幾列是同一行。行號 Overlay0，
  游標所在那一行的行號 Text。行號欄**至少兩位**：寬度取 max(2, 最大行號的位數)。1–99 行不跳；到第 100 行、第 1000 行……每多一位
  跳寬一次，內容往右一格 —— 行數是使用者自己打出來的，看得出為什麼。行數沒有上限。
- **大小**：寬度與高度都取 Rules F7 的上限（`min(terminal 寬 − 2, 120)`、畫面高度 − 2）：內容會跟著打字變多，打開時不知道要多大。
  內容超過框時在框裡捲，游標一直在看得到的地方；放不下時下框右邊寫游標所在的行 `N of M`（以行為單位，跟左邊的行號同一套數字，
  不是畫出來的列）。
- **游標**：「寫」是一格 Lavender 底、Base 字（照 [`input/README`](README-zh_TW.md)）；「移」是一格層色底、Base 字。值的字都是 Lavender。
  兩種狀態的游標停在控制字元上時，整個控制字元畫成 Red 底、Base 字（照 [`input/README`](README-zh_TW.md) 的「貼上的控制字元」）。
- **`\t`**：值裡的 `\t` 畫成 `input_tab_width` 格空白（見下面的 `Tab`），不對齊到哪一格。

## 按鍵

**兩種狀態**：

| 狀態 | 做什麼 | hint |
|---|---|---|
| **寫** | 打字（輸入態）。`Enter` 換行、`Tab` 插入空白（Rules K8）。打開時在這裡 | `Esc:move` |
| **移** | 在「寫」裡按 `Esc` 進來。移動游標；`i`、`a`、`o` 回到「寫」；**`Enter` 確定** | `Enter:save i:write Esc:cancel` |

- **確定就是「移」裡的 `Enter`**。
- **打開時**：在「寫」，舊值直接帶進來，游標在最後；沒有灰字提議（[`input/README`](README-zh_TW.md) 的灰字提議只用在單行）。
- `Esc`：在「寫」裡進到「移」（hint 會換成 `Enter:save`，照著就知道怎麼存）；在「移」裡關掉。內容改過時，先開 confirm 問要不要放棄
  （[`dialog/form`](../dialog/form-zh_TW.md) 的「取消」）。
- **「寫」的編輯鍵**：[`input/README`](README-zh_TW.md) 的那一組，加上多行才要的 —— `↑|↓` 換到上一列、下一列（照畫出來的列，折行也算
  一列）；`←|→` 到行頭、行尾時跨到上一行、下一行；行首的 `Backspace` 跟上一行合併。`Home`、`End` 到整篇的開頭、結尾（跟單行一樣是
  整個值的最前面、最後面）；行頭、行尾在「移」裡用 `0|$`。
- **貼上的換行就是真的換行**：`\n`、`\r\n`，以及單獨的 `\r`（很多終端機貼上時把換行送成 `\r`）。
- **貼上的其他控制字元**：照 [`input/README`](README-zh_TW.md) 的「貼上的控制字元」留在值裡、畫成紅字（`\x1b`），`Backspace` 一次刪
  一整個。值裡有控制字元時，確定（「移」裡的 `Enter`）擋下，不存，錯誤列照單行點名欄位（例：`Notes can't have control characters`），刪掉才能存。換行與 `\t`
  不算。
- **`Tab`**：插入空白，個數是設定 `input_tab_width`（預設 4，放在每個 app 的設定檔，Rules E3）。值裡存的就是空白；`Backspace`
  一次刪一個。貼上的 `\t` 照存，不偷改使用者貼進來的內容，畫面上畫成 `input_tab_width` 格空白。
- **「移」的鍵**：移動照 Rules K12 —— `h|j|k|l`、`w|b|e`、`0|$`、`u|d`、`gg|G`。`i` 在游標前開始寫、`a` 在游標後開始寫、`o` 在下面開新的
  一行再寫（照 vim）。
- 「移」不是模式，也不是輸入態：core key 照 Rules K1（`?` 打開 key reference）。

**為什麼**：打開時帶入舊值：多行文字改的多半是補一句、改幾個字，打開就能改；「寫」裡的 `Tab` 是縮排，收不了提議。整段換掉要
在「寫」裡自己刪，這種情況少。多行的 `Enter` 要拿來換行，確定只能換一個鍵或換一個狀態；有兩種狀態，「移」裡的 `hjkl` 可以移動、`Enter` 可以確定，
不用另外的送出鍵。兩種狀態的游標顏色不同：同一個字母在「寫」裡是打字、在「移」裡是移動，不看 hint 也要分得出來；層色在家族裡
本來就是「cursor 停在這裡」。`Tab` 插空白、不對齊：終端機裡沒辦法靠 tab 對齊，使用者按 `Tab` 要的就是空幾格；空幾格由使用者設定。
框一律開到最高：跟寬度「內容不確定取上限」同一個道理，舊值很短時也不會打幾行就開始捲。

## 值

在表單與 panel 上：第一行；後面還有就加 `…`（[`input/README`](README-zh_TW.md)）。
