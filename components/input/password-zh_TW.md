# password（遮蔽輸入）

**Language**: [English](password.md) · 繁體中文

## 用途

輸入不顯示出來的值：密碼、PIN、passphrase。

## 長相

- 骨架照 [`text`](text-zh_TW.md) 的「長相」（單行 input popup）。
- **遮罩有兩個方案，app 依用途挑**（user 2026-10-07 定）：

  | 方案 | 樣子 | 適合 |
  |---|---|---|
  | **一般** | 每個字一個 `•`，靠左（sshu、webu） | 表單裡的密碼、一般的密碼框 |
  | **解鎖** | 每個字一顆 `●`，顆與顆之間空一格，置中、往兩側長（locku） | 螢幕解鎖、PIN、驗證碼 —— 整個框就為了輸入這一個值（user：像 macOS 的驗證碼） |

  遮罩用值的顏色（Lavender）。「已經有密碼」的 8 個灰點用同一個方案的字。放不下時照 text 的長值規則（游標那一端看得到）。

## 狀態

**已經有密碼時**（user 2026-10-07 定）：

```
│ ••••••••                             │   ← 有舊密碼：固定 8 個灰點（Overlay0），不代表實際長度
```

- 框打開是空的；有舊密碼時，游標後面畫固定 8 個灰點，表示「現在有一個密碼」。不照實際長度畫，免得洩露長度。
- 什麼都沒打，`Enter` 或 `Esc` 都保留舊密碼。
- 直接打字：換成新密碼，灰點隱藏。
- 沒有 `Tab`：看不到的舊密碼沒辦法在上面改。
- 新密碼要不要打兩次確認（locku 設 PIN 的 `new PIN` → `confirm PIN`）是 app 的流程，components 不規定。

## 按鍵

- 貼上照 [`text`](text-zh_TW.md) 的「貼上的換行與 Tab」（遮罩照樣遮罩）。
- **`Backspace` 一次清全部，不一個一個字刪**（user 2026-10-07）：有打字時清掉打的全部，回到灰點（保留舊密碼）；空的時候清掉
  舊密碼，灰點消失，這時 `Enter` 存成沒有密碼。hint 加 `Backspace:clear`。
- **字元一律接在尾端**；`←`/`→`、`Home`/`End`、`Delete` 沒有作用：看不到字、`Backspace` 又一次清全部，移游標沒有意義（從
  user 的 `Backspace` 推論）。

## 在表單與 panel 上怎麼顯示

- 設了密碼：固定 8 個 `•`，值的顏色，不洩露長度（webu 頁面上現在畫實際長度、最多 12 個，要改）。沒設：照 text 的空值規則，
  灰字寫空著代表什麼（`not set`）。
