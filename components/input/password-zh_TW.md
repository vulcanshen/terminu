# password（遮蔽輸入）

**Language**: [English](password.md) · 繁體中文

## password.1 用途

輸入不顯示出來的值：密碼、PIN、passphrase。

## password.2 長相

- 骨架照 [`input/README`](README-zh_TW.md) 的單行 input popup。
- **遮罩有兩個方案，選哪一個 app 可以自行決定，依用途挑**：

  | 方案 | 樣子 | 適合 |
  |---|---|---|
  | **一般** | 每個字一個 `•`，靠左（sshu、webu） | 表單裡的密碼、一般的密碼框 |
  | **解鎖** | 每個字一顆 `●`，顆與顆之間空一格，置中、往兩側長（locku） | 螢幕解鎖、PIN、驗證碼 —— 整個框就為了輸入這一個值（像 macOS 的驗證碼） |

  遮罩用值的顏色（Lavender）。「已經有密碼」的 8 個灰點用同一個方案的字。放不下時照 README 的「值比框長時」（游標那一端看得到）。
- **解鎖的游標**：在下一顆 `●` 會出現的位置（最後一顆後面空一格）；打滿最後一碼時停在最後一顆上，不再多一格。置中時連游標一起算：
  打了 n 碼（沒滿）是 2n + 1 格，打滿 N 碼是 2N − 1 格。

```
┃                 ● ● ● █                 ┃   ← 打了 3 碼：游標在下一顆會出現的位置
┃         ● ● ● ● ● ● ● ● ● ● ● █         ┃   ← 打滿 12 碼：游標停在最後一顆上（Lavender 底、Base 的 `●`），不多一格
```

- **解鎖沒有 `nf-fa-angle_right`**：整個框只為輸入這一個值，置中的點一看就知道在這裡打；箭頭是在有說明的框裡指出打字列。
- **解鎖也沒有說明列**，理由同上。要輸入什麼由標題講：鎖定畫面 `UNLOCK`；改 PIN 的三步 `CURRENT PIN`、`NEW PIN`、`CONFIRM PIN`。
  框裡是兩列空白、打字列、一列空白、錯誤列，連框 7 列，打字列在正中間：

```
┏━UNLOCK━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃                                           ┃
┃                                           ┃
┃                  ● ● ● █                  ┃
┃                                           ┃
┃                                           ┃   ← 錯誤列
┗━ Enter:unlock Backspace:clear Esc:cancel ━┛
```

- **寬度**：有長度上限時（例：PIN），寬度照內容確定（[`layout/popup`](../layout/popup-zh_TW.md) 的寬度）。

## password.3 狀態

**已經有密碼時**：

```
┃  █•••••••                           ┃   ← 有舊密碼（一般）：固定 8 個灰點（Overlay0），游標壓在第一顆上，不代表實際長度
```

```
┃             █ ● ● ● ● ● ● ●             ┃   ← 有舊密碼（解鎖）：8 顆灰點間隔一格、整串置中，游標壓在第一顆上
```

- 框打開是空的；有舊密碼時畫固定 8 個灰點，表示「現在有一個密碼」。灰點從游標那一格開始：游標壓在第一顆上（Lavender 底、Base 的點），
  其他 7 顆 Overlay0 —— 跟 [`input/README`](README-zh_TW.md) 的灰字提議一樣。解鎖樣式的 8 顆間隔一格、整串置中（15 格）。不照實際長度畫，
  免得洩露長度。
- 什麼都沒打，`Enter` 或 `Esc` 都保留舊密碼。
- 直接打字：換成新密碼，灰點隱藏。
- 沒有 `Tab`：看不到的舊密碼沒辦法在上面改。
- 新密碼要不要打兩次確認（例：locku 設 PIN 的 `NEW PIN` → `CONFIRM PIN`）是 app 的流程。
- **錯太多次而暫停收值時**（例：locku 連錯 PIN 之後的冷卻）：倒數寫在錯誤列，暫停期間除了 `Esc` 都吞掉（[`layout/popup`](../layout/popup-zh_TW.md)
  的錯誤列）。

灰點不是灰字提議：它背後沒有文字可以收，hint 也不寫 `Tab`；跟提議一樣的地方只有「什麼都沒打就 `Enter`，保留舊的」。

## password.4 按鍵

- 貼上照 [`input/README`](README-zh_TW.md) 的「貼上的控制字元」（遮罩照樣遮罩）。
- **`Backspace` 一次清全部，不一個一個字刪**：有打字時清掉打的全部，回到灰點（保留舊密碼）；空的時候清掉舊密碼，灰點消失，這時
  `Enter` 存成沒有密碼。hint 加 `Backspace:clear`。
- **字元一律接在尾端**；`←|→`、`Home|End`、`Delete` 沒有作用。

**為什麼**：看不到字，移游標沒有意義；打錯了也不知道錯在哪，`Backspace` 一次清掉重打最快。

## password.5 值

不去掉前後的空白字元（空白字元也可能是密碼的一部分）。在表單與 panel 上：設了密碼是固定 8 個 `•`、Text（表單與 panel 上值的顏色），不洩露長度；沒設照空值的規則
（例：`not set`）。
