# text（一行文字）

**Language**: [English](text.md) · 繁體中文

## text.1 用途

輸入一行文字：名稱、網址、指令、路徑。多行的用 [`textarea`](textarea-zh_TW.md)；只收數字的用 [`number`](number-zh_TW.md)；不顯示出來的用
[`password`](password-zh_TW.md)。

## text.2 長相

單行 input popup 的骨架（[`input/README`](README-zh_TW.md)）。值比框長時照 README 的「值比框長時」。

## text.3 按鍵

編輯鍵、灰字提議、貼上的控制字元，都照 [`input/README`](README-zh_TW.md)。

## text.4 值

確定時去掉前後的空白字元（[`README`](README-zh_TW.md) 的「值」）；在表單與 panel 上照 README 的「在表單與 panel 上怎麼顯示」。
