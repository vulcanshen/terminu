# text (one line of text)

**Language**: English · [繁體中文](text-zh_TW.md)

## text.1 Purpose

Entering one line of text: a name, a URL, a command, a path. For several lines use [`textarea`](textarea.md); for
digits only, [`number`](number.md); for a value not shown, [`password`](password.md).

## text.2 Look

The skeleton of a one-line input popup ([`input/README`](README.md)). A value longer than the box follows "When the value
is longer than the box" in the README.

## text.3 Keys

Editing keys, the grey suggestion, and pasted control characters all follow [`input/README`](README.md).

## text.4 Value

Leading and trailing whitespace is trimmed when confirmed ([`README`](README.md), "Value"); in a form or a panel it follows "How a value shows in a form and
a panel" in the README.
