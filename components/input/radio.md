# radio (one of a few)

**Language**: English · [繁體中文](radio-zh_TW.md)

## Purpose

One of a few: drawn in the form or panel itself, chosen with `Enter`. With more options than fit, use [`select`](select.md).

## Look

- Radio glyphs: chosen `󰐾`, not chosen `󰐽` (the pair sshu and webu use today; select uses it too, see [`select`](select.md)).
